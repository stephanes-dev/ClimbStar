# ClimbStar

Geo-visualizer ClimbStar leverages cloud-agnostic infrastructure for scalable, real-time route planning via AI-driven optimizer and scheduler.

ClimbStar is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/ClimbStar.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Runtime options can be set in the config file or overridden per call. The most commonly changed values are:
- **timeout**: how long operations may run before failing
- **retries**: how many times a failed operation is re-attempted
- **cache**: where temporary results are stored
